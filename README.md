# CookFlow

[Open CookFlow](https://joeldreimer13-lgtm.github.io/cookflow/)

A mobile-friendly shopping list and cooking checklist. Add stores and items, check off purchases, collapse sections, and track percentage progress. The website saves automatically in the current browser.

## iPhone and Apple Watch companion

[Download the Xcode source project](CookFlowApple.zip) · [Installation and syncing guide](APPLE-SETUP.md) · [Apple build checks](https://github.com/joeldreimer13-lgtm/cookflow/actions/workflows/apple-apps.yml)

The native Watch companion has store and cooking checklists, checkboxes, percentage bars, and saved offline changes. Use the native iPhone app to edit lists and sync with the paired Watch. Bring existing Safari or Home Screen lists across with **Move or back up your lists → Copy for companion**, then Paste in the native iPhone app.

The ZIP is source code, not an installable App Store or TestFlight release. Apple signing and physical-device setup are still required; see the installation guide.
