# CookFlow

[Open CookFlow](https://joeldreimer13-lgtm.github.io/cookflow/)

Save recipes in folders, search by name or ingredient, and reopen each recipe with its own saved cooking progress. Add or remove stores and shopping items, collapse sections, and track percentage progress. Everything saves on the current device.

## Recipe library

Open **My recipes**. Tap **+ Add recipe** to paste ingredients and steps, enter a name, choose a folder, and save. Use **Folders** to organize your collection. Search covers titles, ingredients, steps, and folder names. The **•••** menu edits, moves, copies, or removes a saved recipe. Removing a folder keeps its recipes in Unfiled; deletions offer Undo.

Your existing current checklist is preserved in the library. **Move or back up your lists** now exports the complete library and folders as well as the shopping list. Older backups still import.

## iPhone and Apple Watch companion

[Download the Xcode source project](CookFlowApple.zip) · [Installation and syncing guide](APPLE-SETUP.md) · [Apple build checks](https://github.com/joeldreimer13-lgtm/cookflow/actions/workflows/apple-apps.yml)

The native iPhone app includes the same recipe library. The Watch companion has shopping and cooking checklists, checkboxes, percentage bars, and saved offline changes. Use the native iPhone app to edit lists and sync with the paired Watch.

The ZIP is source code. Native device installation requires Apple signing; see the guide. The Safari/Home Screen website updates on reload; installed native apps need the updated build.
